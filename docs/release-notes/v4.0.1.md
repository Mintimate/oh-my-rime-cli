# Oh My Rime v4.0.1

## 修复

- 修复更新方案时，长文件路径把右侧目标目录和进度卡片撑出窗口的问题。
- 进度信息、长错误链接和运行日志现在自动换行；默认窗口和最小窗口都能正常显示。
- 目录路径过长时显示省略号，可悬停查看完整路径。
- 修复 CNB 发布时因附件汇总列表未列出 `latest.json` 而误判上传失败的问题；现在逐个下载附件校验大小及 SHA-256，再公开版本。
- 完善 GitHub 草稿下载地址处理和发布验签环境。

## 更新与下载

v4.0.0 用户可在左下角点击“检查应用更新”，下载并安装本版本；也可从 [GitHub Releases](https://github.com/Mintimate/oh-my-rime-cli/releases/tag/v4.0.1) 或发布完成后的 [CNB 镜像](https://cnb.cool/Mintimate/rime/oh-my-rime-cli/-/releases) 手动安装。旧 Go/Wails 版本和独立 CLI 需要手动更新。

macOS 安装包使用 ad-hoc 签名，尚未经过 Apple 公证。首次打开若被拦截，请确认来源后在“系统设置 → 隐私与安全 → 仍要打开”确认。Windows 安装包尚未配置代码签名。
