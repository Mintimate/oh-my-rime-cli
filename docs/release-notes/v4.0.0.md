# Oh My Rime v4.0.0

桌面端从 Go/Wails 迁移至 Tauri 2 + React + Rust，GUI 与独立 CLI 共用更新核心。

## 新界面与配置更新

- 全新桌面界面，支持薄荷方案、万象模型、万象词库与自定义资源更新。
- 提供平台配置目录预设、任务进度、会话日志，以及更新前备份和失败恢复。
- 修复启动白屏，加入项目图标、亮色 / 跟随系统 / 暗色切换和 OMR 版本标识。
- 调整默认窗口布局，避免初始界面出现不必要的滚动条。

## 应用自动更新

- 启动时检查新版，也可从左下角手动检查；支持查看说明、下载进度、签名校验和安装后重启。
- 可选择接收测试版；正在更新 Rime 配置时不能同时安装应用更新。
- 从旧 Go/Wails 版本升级需手动安装一次本版本，独立 CLI 仍需手动更新。

## 下载

- macOS：按 Apple Silicon / Intel 选择 DMG，拖入“应用程序”后运行。
- Windows x64：选择 MSI 或 EXE 安装包。
- Linux x64：选择 AppImage、DEB 或 RPM。
- 独立 CLI：`cli-macos-arm64`、`cli-macos-x64`、`cli-linux-x64`、`cli-windows-x64.exe`。
- `.app.tar.gz`、`.sig`、`latest.json` 供应用更新使用。

GitHub 发布通过验证后会自动同步至 [CNB Releases](https://cnb.cool/Mintimate/rime/oh-my-rime-cli/-/releases)。两个平台提供相同安装包及签名；CNB 的更新清单使用 CNB 下载地址。应用内更新目前从 GitHub 检查。

macOS 安装包使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若提示无法验证，确认来源后在“系统设置 → 隐私与安全 → 仍要打开”中确认。Windows 安装包尚未配置代码签名。
